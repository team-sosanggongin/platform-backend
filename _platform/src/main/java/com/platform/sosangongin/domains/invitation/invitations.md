# 초대 종류

1. 앱을 사용중인 사용자 초대 방식
3. 앱을 사용하지 않는 사용자 초대 방식(1회용 링크 방식)
3. 초대 공개 링크 방식

## 앱을 사용중인 사용자 초대 방식

유저 코드를 이용해 사장님은 유저에게 직접 초대를 보낼 수 있음. 이 경우, 유저는 이미 로그인이 완료되었기 때문에 별도의 로그인 처리 없이
매장에 등록되는 절차를 진행. 

## 앱을 사용하지 않는 사용자 초대 방식

앱을 사용하지 않는 사용자를 매장에 초대하는 방식으로, 사장님은 1회용 링크를 발급받고, 이를 나름의 방법으로 직원에게 전달
이를 받은 직원이 링크를 클릭 후, 앱 설치 및 회원가입, 최종적으로 초대에 응하는 것이 완료되면 해당 링크는 더이상 처리가 되면 안됨.

또한 이용기간에 제한이 있으며, 만료되면 다시 사용할 수 없어야 함.

## 초대 공개 링크 방식

사장님은 초대링크를 생성하고, 매장 등에 비치하게 됨. 이후, 사용자는 해당 링크를 통해 접근하며, 앱을 사용중이지 않을 경우, 회원가입을 진행

이후, 매장 가입을 요청하면, 사장님은 리스트를 통해 요청을 확인하고, 수용 여부를 판단.
